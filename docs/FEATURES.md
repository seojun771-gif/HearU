# 기준 모델 특징 기록 (MFCC + 주파수 변화 + 소리 크기 변화)

- 코드: `ai/features.py` (특징 추출), `ai/train_features.py` (학습·평가)
- 결과: `ai/results/<이름>.md`·`.json` / 모델: `ai/models/<이름>.joblib`
- 실행: `python train_features.py` (기준 모델) / `python train_features.py --data <폴더> --name <이름>` (두 번째 모델)

## 1. 전처리 (세 특징 공통)

| 단계 | 내용 |
|---|---|
| 입력 | 원본 WAV → 16kHz mono float (`librosa.load`) |
| 구간 | 1.5초(24,000샘플). 길면 0.1초 간격으로 훑어 에너지가 가장 큰 1.5초를 자르고, 짧으면 뒤에 0을 채움 |
| 정규화 | 최대 절댓값이 1이 되도록 나눔 (마이크 거리·볼륨 차이 완화) |
| 분석 창 | STFT n_fft 512 (32ms), hop 256 (16ms), Hann 창 → 약 94프레임 |
| 증강 (학습용만) | 볼륨 ×0.5~1.5, 시간 이동 ±0.2초, 배경 잡음 최대 2%. 파일당 3개 |

## 2. 특징별 계산 방법 (총 136차원)

### MFCC (120차원)

| 항목 | 값 |
|---|---|
| 계수 | 40개 (c0~c39). c0는 전체 에너지(소리 크기)에 해당, c1~c39는 스펙트럼 모양 |
| 멜 필터 | 128개, 0~8,000Hz |
| 계산 | 파워 스펙트럼 → 멜 필터 → log(dB) → DCT-II (librosa 기본) |
| 요약 | 계수별 **평균 40** + **표준편차 40** + **1차 변화량(delta, 9프레임) 평균 40** |

### 주파수 변화 (10차원)

| 특징 | 계산 |
|---|---|
| centroid_mean / std | 프레임별 스펙트럼 중심 주파수의 평균 / 표준편차 |
| centroid_change | 중심 주파수의 프레임 간 변화량 절댓값 평균 |
| rolloff_mean / std | 에너지 85%가 모이는 주파수의 평균 / 표준편차 |
| dominant_mean / std | 80Hz 이상에서 가장 강한 주파수의 평균 / 표준편차 |
| dominant_change | 대표 주파수의 프레임 간 변화량 절댓값 평균 |
| flux_mean / std | 음량을 정규화한 스펙트럼의 프레임 간 변화량(유클리드 거리) 평균 / 표준편차 |

### 소리 크기 변화 (6차원)

| 특징 | 계산 |
|---|---|
| db_mean / db_std | 프레임 에너지 dB의 평균 / 표준편차 |
| db_range | 최대 dB − 최소 dB |
| db_change | 프레임 간 dB 변화량 절댓값 평균 |
| db_max_rise | 한 프레임 사이 가장 크게 커진 dB |
| db_rise_count | 한 프레임 사이 6dB 넘게 커진 횟수 (두드림처럼 순간적인 소리) |

## 3. 모델·평가

| 항목 | 값 |
|---|---|
| 모델 | StandardScaler → MLP (은닉층 128, 64 / alpha 1e-3 / early stopping / seed 42) |
| 평가 | 파일 단위 5겹 층화 교차검증. 증강은 학습 폴드에만 적용 (같은 녹음이 시험에 섞이지 않게) |
| 최종 모델 | 전체 데이터 + 증강으로 다시 학습해 저장 |

## 4. 결과

### 모델 1: 기준 모델 (`baseline`, 2026-11-22)

데이터 `ai/data` 184개: UNKNOWN 80 · FIRE 10 · BABY_CRY 20 · DOORBELL 31 · KNOCK 43
(ESP32 직접 녹음 30 + 이전 직접 녹음 31 + ESC-50 공개 데이터 123)

|---|---|---|---|---|---|
| 기타 | 80 | 0.77 | 0.79 | 0.78 | 오인식 ≤10% |

| 초인종 | 31 | 0.96 | 0.77 | 0.86 | |
| 노크 | 43 | 0.78 | 0.91 | 0.84 | |

해석
- 세 조합 차이(정확도 0.76~0.79)는 파일 2~6개 차이라 데이터 수에 비해 의미 있는 차이로 보기 어렵다.
- 화재 녹음 10개는 대표 주파수가 대부분 800~1,600Hz로 초인종과 겹치고, 일반 감지기(약 3kHz)와 다르다. 화재 데이터 추가가 가장 시급하다.
- 기타 소리를 노크로 잘못 본 11개는 개 짖음·발소리·시계 소리처럼 순간적인 소리였다.
