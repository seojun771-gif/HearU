# 코드 개요 (1분 요약)

## 이 코드는 무엇인가?

**생활소리를 듣고 "어떤 소리인지" 맞히는 AI 코드**입니다. 소리를 6가지 중 하나로 분류하고, 그 결과를 FPGA 장치로 보낼 한 줄 메시지로 만들어 줍니다. 화재경보음은 AI와 별개로 **규칙 검출기**가 한 번 더 확인합니다.

| 번호 | 소리 | 번호 | 소리 |
|---|---|---|---|
| 1 | 화재경보기 (FIRE) | 4 | 문 두드림 (KNOCK) |
| 2 | 아기 울음 (BABY_CRY) | 5 | 사람 호출 (CALL) |
| 3 | 초인종 (DOORBELL) | 0 | 기타 (UNKNOWN) |

## 동작 방식: 두 갈래

```
          ┌─ ① AI 모델 (6종 분류, 학습 필요) ────────────────────────────┐
소리 ─────┤  숫자로 요약(MFCC) → AI가 판단 → 확신 정도 확인 → FPGA용 메시지 │
          └──────────────────────────────────────────────────────────────┘
          ┌─ ② 화재 규칙 검출기 (화재만, 학습 불필요, 안전망) ─────────────┐
          └─ 3kHz대 고음이 정해진 리듬으로 반복되는지 확인 ───────────────┘
```

**① AI 모델**
1. **숫자로 요약**: 소리의 주파수 모양을 120개 숫자(MFCC)로 바꿉니다.
2. **AI가 판단**: 작은 신경망(MLP)이 6개 소리 중 어느 쪽에 가까운지 확률을 계산합니다.
3. **확신 정도 확인**: 80% 이상이면 확정, 60~80%는 약한 알림, 60% 미만이면 "기타"로 처리합니다.
4. **메시지 생성**: `RESULT,1,FIRE,89,1` 형태(클래스번호, 이름, 신뢰도, 우선순위)로 만들어 FPGA에 보냅니다.

**② 화재 규칙 검출기**
- 연기감지기 경보음의 특징(약 3kHz 고음, "삐-삐-삐-" 반복 리듬)을 직접 확인합니다.
- 리듬이 3번 이어지면 `CONFIRMED`(확정), 2번이면 `CANDIDATE`(의심)입니다.
- AI 모델이 화재를 놓쳐도 잡을 수 있게 하는 안전망입니다.

## 파일 7개

| 파일 | 역할 |
|---|---|
| `shared/labels.json` | 소리 종류, 번호, 우선순위, 확신 기준을 적어 둔 약속 파일 |
| `ai/common.py` | 소리를 숫자로 바꾸는 함수 (학습·추론 공용) |
| `ai/train.py` | 녹음 파일로 AI를 학습시키고 성능을 출력 |
| `ai/infer.py` | 학습된 AI로 새 소리를 분류하고 메시지를 생성 (파일 또는 마이크) |
| `ai/fire_rule.py` | 화재경보음 규칙 검출기 (AI 모델과 독립) |
| `ai/test_fire_rule.py` | 화재 규칙 검출기 자동 테스트 (합성 소리) |
| `ai/check_data.py` | 수집한 녹음의 개수·품질 점검 |

## 사용법

```powershell
python check_data.py                  # 녹음 개수·품질 점검
python train.py                       # 학습 (ai/data/ 폴더에 소리별 녹음 필요)
python infer.py sample.wav            # 파일 하나 분류
python infer.py --mic                 # 마이크로 실시간 분류
python fire_rule.py alarm.wav         # 화재 규칙 검사 (모델 불필요)
python -m unittest test_fire_rule -v  # 화재 규칙 테스트
```

## 현재 상태 (2026-11-09 기준)

- **되는 것**: 학습, 파일/마이크 분류, 확신도 판정, FPGA용 메시지 문자열 생성, 화재 규칙 검출(합성 소리 테스트 15개 통과), 녹음 점검
- **아직 없는 것**: 실제 녹음 데이터 대부분(현재 **doorbell 11개뿐**), FPGA와의 실제 UART 연결, 백엔드·앱
- **실제 성능은 측정하지 않았습니다.** 화재 규칙도 합성 소리로만 검증했고, 학습 데이터에 클래스가 하나뿐이라 모델 정확도 수치는 의미가 없습니다.
