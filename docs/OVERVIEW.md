# 코드 개요 (1분 요약)

## 이 코드는 무엇인가?

**생활소리를 듣고 "어떤 소리인지" 맞히는 AI 코드**입니다. 소리를 6가지 중 하나로 분류하고, 그 결과를 FPGA 장치로 보낼 한 줄 메시지로 만들어 줍니다.

| 번호 | 소리 | 번호 | 소리 |
|---|---|---|---|
| 1 | 화재경보기 (FIRE) | 4 | 문 두드림 (KNOCK) |
| 2 | 아기 울음 (BABY_CRY) | 5 | 사람 호출 (CALL) |
| 3 | 초인종 (DOORBELL) | 0 | 기타 (UNKNOWN) |

## 동작 방식

```
소리 → ① 숫자로 요약 → ② AI가 판단 → ③ 확신 정도 확인 → ④ FPGA용 메시지
```

1. **숫자로 요약**: 소리의 주파수 모양을 120개 숫자(MFCC)로 바꿉니다.
2. **AI가 판단**: 작은 신경망(MLP)이 6개 소리 중 어느 쪽에 가까운지 확률을 계산합니다.
3. **확신 정도 확인**: 80% 이상이면 확정, 60~80%는 약한 알림, 60% 미만이면 "기타"로 처리합니다.
4. **메시지 생성**: `RESULT,1,FIRE,89,1` 형태(클래스번호, 이름, 신뢰도, 우선순위)로 만들어 FPGA에 보냅니다.

## 파일 4개

| 파일 | 역할 |
|---|---|
| `shared/labels.json` | 소리 종류, 번호, 우선순위, 확신 기준을 적어 둔 약속 파일 |
| `ai/common.py` | 소리를 숫자로 바꾸는 함수 (학습·추론 공용) |
| `ai/train.py` | 녹음 파일로 AI를 학습시키고 성능을 출력 |
| `ai/infer.py` | 학습된 AI로 새 소리를 분류하고 메시지를 생성 (파일 또는 마이크) |

## 사용법 (3줄)

```powershell
python train.py                # 학습 (ai/data/ 폴더에 소리별 녹음 필요)
python infer.py sample.wav     # 파일 하나 분류
python infer.py --mic          # 마이크로 실시간 분류
```

## 현재 상태
